HOW TO USE THIS FILE
--------------------
* Do the parts IN ORDER. Later parts use the data created in earlier parts.
* Every step has:   ACTION  → what to do
                    EXPECT  → what should happen
                    RESULT  → tick PASS or FAIL, write notes if anything differs
* If a step FAILS: write what you saw in the step's Notes line AND add a row to
  the ISSUE LOG at the end (screenshot names help). Then continue if you can.
* All test data starts with "TST" / "Test" so it is easy to find and clean up.
* The test month is SEPTEMBER 2026 (30 days — this keeps the salary maths
  simple: 1 day = monthly gross ÷ 30).
